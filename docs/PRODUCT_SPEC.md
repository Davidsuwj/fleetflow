# 功能需求

## 員工操作

以工號、密碼登入；介面只顯示當前登入員工，無切換身分選單或管理者操作。「申請用車」按鈕只出現在「我的申請」頁，其他頁不重複放置；「車輛預約」保留大家的預約與查空車。

| 頁面 | 功能 |
|---|---|
| 登入 | 工號、密碼、錯誤提示、登入／登出 |
| 我的用車 | 個人數量、下一趟行程 |
| 我的申請 | 新增、修改、取消、刪單、搜尋、申請／行程狀態篩選、登記歸還 |
| 車輛預約 | 大家的未完成預約與使用中安排，起迄查空車 |
| 車輛紀錄 | 選車牌、車況、該車保養／加油紀錄切換 |
| 個人統計 | 個人申請、行程、歸還、預約時數、近六個月數量 |

## 申請與防呆

用途不可空白，起日在未來、迄日晚於起日。所有時間依 Asia/Taipei 顯示。可自動安排或指定車輛，表單依起迄更新可選車牌，已占用的車不能選。

預約為 [起, 迄)，兩時段重疊條件為既有起 < 新迄且既有有效迄 > 新起，相鄰可借。後端先鎖員工，再依車輛順序取鎖、重查預約；同車或同員工重疊均拒絕。同車併發只會一人成功；指定車已被借用時回傳 409，不悄悄換車。成功在一筆交易寫入 approved 申請與派車。

大家的預約為所有員工可查閱的共享資料，包含車牌、姓名、用途及起迄；各人的電話、密碼及個人統計不共享。查空車結果僅代表查詢當下，真正送出會再驗證。

## 修改、取消、刪單與歸還

本人尚未開始、尚未歸還的申請可修改。修改查空車可以排除自己的本筆預約；不能排除別人的單。修改成功才改原申請與派車，失敗 rollback。

取消保留 cancelled 申請並刪預約。刪單確認後刪除申請及未來派車、釋放車輛。已開始／已歸還不可修改、取消或刪除；行程開始後才可歸還，重複歸還拒絕。

## 密碼與紀錄

依作業需求 employees.password 明碼保存，未設定密碼者不能登入。公司以建置工具設定或重設，沒有網站管理者頁。一般 API 不回傳密碼。

保養與加油均為弱實體，日期為部分鍵；PK 為車輛＋日期，同車同日各一筆。車輛頁初始只顯示可選車牌；點選後顯示該車的紀錄，切換保養或加油，依日期由新至舊排列。切換車牌預設顯示保養，登出清除選車狀態。

DEMO-101～104 各有 2 筆保養、3 筆加油模擬資料；固定日期匯入採 ON CONFLICT DO NOTHING，不覆寫原資料。

## 介面與範圍

繁體中文、鍵盤可操作；手機使用底部五頁導覽，日期輸入上下排列，申請與預約逐筆卡片顯示，保養項目換行；桌面使用表格。保留欄位標籤、錯誤訊息與刪單確認。沒有密碼找回、管理者、GPS、通知、付款或分頁。逾期未歸還不會自動延長原預約。

工號：`employees.employee_code` 為 UNIQUE 字串，格式 `EMP0001` 起，從 employee_id 產生（超過四碼不截斷）。登入只接受 employee_code＋password；數字流水號不能登入。employee_id 仍是內部 PK／FK，保留既有申請與派車關聯。工號不加 PK 底線。

「我的申請」集中顯示申請、車牌、使用期間、已預約／使用中／已歸還狀態與歸還操作。「申請用車」按鈕只出現在「我的申請」頁。
手機版車輛預約的出發／歸還日期上下排列，各占一列完整寬度；日期輸入不得超出欄位，桌面保留同列排列。
